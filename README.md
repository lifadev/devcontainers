# Development Containers

Curated [development containers](https://containers.dev) for fast,
reproducible, and batteries-included developer experience on Debian.

Amuse-Bouche?

```bash
mkdir -p .devcontainer
curl -fLsS \
  "https://github.com/lifadev/devcontainers/blob/main/.devcontainer/devcontainer.json?raw=true" \
  >".devcontainer/devcontainer.json"
```
